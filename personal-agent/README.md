# Personal Agent — Telegram Bot

Многофункциональный личный агент в Telegram.

## Модули

| # | Модуль | Описание |
|---|--------|----------|
| 1 | **Планировщик задач** | Напоминания сообщением, голосом (TTS) и на телефон |
| 2 | **Голосовой ввод** | Распознавание задач через OpenAI Whisper |
| 3 | **Google Calendar** | OAuth-подключение и синхронизация событий |
| 4 | **Twilio** | Реальные телефонные звонки-напоминания |
| 5 | **Заметки + AI** | Быстрые заметки и свободный диалог |

## Быстрый старт

### Windows (самый простой способ)

1. Скопируйте `env.example` → `.env` и вставьте `BOT_TOKEN`
2. **Дважды кликните** `start-bot.bat`

### Вручную

```bash
cd personal-agent
pip install -r requirements.txt
cp env.example .env
# Укажите BOT_TOKEN (обязательно) и OPENAI_API_KEY (рекомендуется)
python -m bot.main
```

## Примеры

```
Завтра в 9:00 напомни позвонить маме
Через 30 минут проверить духовку — на телефон
Заметка: идея для стартапа
```

Голосовое сообщение → распознавание → создание задачи.

## Команды

| Команда | Описание |
|---------|----------|
| `/tasks` | Активные задачи |
| `/calendar` | Подключить Google Calendar |
| `/phone +7999...` | Привязать телефон для звонков |
| `/notes` | Список заметок |
| `/note текст` | Создать заметку |
| `/help` | Справка |

Кнопки меню: 📋 Мои задачи · 📆 Сегодня · 📝 Заметки · 📅 Календарь · 📞 Телефон

## Переменные окружения

| Переменная | Обязательно | Описание |
|------------|-------------|----------|
| `BOT_TOKEN` | ✅ | Токен @BotFather |
| `OPENAI_API_KEY` | рекомендуется | Парсинг, Whisper, AI-чат |
| `GOOGLE_CLIENT_ID/SECRET` | для календаря | OAuth Google |
| `TWILIO_*` | для звонков | Account SID, Auth Token, From Number |

## Архитектура

```
personal-agent/
├── bot/handlers/     # Telegram routers
├── services/         # Бизнес-логика
├── database/         # SQLAlchemy + миграции
└── api/              # OAuth callback сервер
```

## Ограничения

- «Звонок» в Telegram = голосовое сообщение (TTS)
- Реальный звонок на телефон = Twilio + `/phone`
- Google OAuth требует публичный redirect URI (ngrok для локальной разработки)
