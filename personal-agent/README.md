# Personal Agent — Telegram Bot

Многофункциональный личный агент в Telegram. Первый модуль — **планировщик задач** с напоминаниями сообщением и голосом.

## Возможности

- Создание задач естественным языком («Завтра в 9:00 напомни позвонить маме»)
- Напоминания **сообщением** в чат
- Напоминания **«звонком»** — голосовое сообщение (TTS)
- Список, отмена и отметка выполнения задач
- Отложить напоминание на 15 минут
- Часовой пояс пользователя (`/timezone Europe/Moscow`)
- Планировщик переживает перезапуск бота (APScheduler + SQLite)

## Быстрый старт

```bash
cd personal-agent
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp env.example .env
# Укажите BOT_TOKEN в .env
python -m bot.main
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `OPENAI_API_KEY` | Опционально — улучшенный разбор задач |
| `DEFAULT_TIMEZONE` | Часовой пояс по умолчанию |
| `TTS_VOICE` | Голос edge-tts для напоминаний |

## Примеры фраз

## Ограничения Telegram

Боты не могут совершать телефонные звонки. «Звонок» реализован как **голосовое напоминание** с синтезом речи. Для реальных звонков на номер телефона можно добавить модуль Twilio.
